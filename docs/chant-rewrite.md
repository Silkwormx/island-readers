# Chant pages for Units 7 to 12

Each item below is one page. A page is one idea, one alliteration, or one short poem. Separate ideas are not mixed on the same page or read as one sequence.

Lines that already share an idea stay together. A line is rewritten only when it does not stand on its own. Nothing here is in the app yet: no code changes and no new pictures for these pages.

The app still stores 2 to 4 lines as one chant. These pages are the proposed split.

## 7.1 Compound words

Pattern: two small words in one big word. Heart words in play: one, two.

Old:

```
Clap it: sun, set.
Clap it: cob, web.
Hilltop, laptop,
clap, clap, and stop!
```

New pages:

1. Clap it: sun, set.
2. Clap it: cob, web.
3. Clap it: hill, top.
4. Clap it: lap, top.

Hilltop and laptop were two compounds on one line. Each compound is now its own page, in the same clap pattern. "Clap, clap, and stop!" was only a closer, so it is not a page.

## 7.2 Two closed syllables

Pattern: two closed syllables. Heart words in play: come, some.

Old:

```
Rabbit, rabbit, hop, hop, hop.
Kitten, kitten, stop, stop, stop.
Muffin, napkin, picnic fun,
clap, clap, clap, and off we run!
```

New pages:

1. Rabbit, rabbit, hop, hop, hop.
2. Kitten, kitten, stop, stop, stop.
3. Muffin, muffin, yum, yum, yum.
4. Napkin on a lap.
5. Picnic in the sun.

The rabbit and the kitten were already one idea each. Muffin, napkin, and picnic were three ideas in one line, so each one has a page. "Clap, clap, clap, and off we run!" was only a closer.

## 7.3 Open and closed syllables

Pattern: open or closed syllables. Heart words in play: many, any.

Old:

```
Go, go, robot, go!
No, no, robot, no!
Hi, pilot, hi!
Zip up, and so we go!
```

New pages:

1. Go, go, robot, go! No, no, robot, no!
2. Hi, pilot, hi!
3. Zip up, and so we go!

The robot lines are one idea: the robot goes, then the robot stops. The pilot is someone else. Zip zipping up is its own send-off.

## 8.2 dge

Old:

```

do not smudge the fudge!
```

New pages:

1. Fudge on the ledge.
2. A wedge on the hedge.

Fudge on a ledge and a wedge in a hedge are two pictures. The nudge, budge, and smudge lines are one warning about the fudge.
